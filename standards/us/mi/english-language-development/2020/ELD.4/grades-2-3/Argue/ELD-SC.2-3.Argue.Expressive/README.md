# ELD-SC.2-3.Argue.Expressive - Construct scientific arguments that ● Introduce topic/phenomenon for an issue...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Construct scientific arguments that ● Introduce topic/phenomenon for an issue related to the natural and designed world(s) ● Make a claim supported by relevant evidence ● Establish a neutral tone ● Signal logical relationships among reasoning, evidence, data, and/or a model when making a claim Features
