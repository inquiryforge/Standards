# ELD-MA.9-12.Argue.Expressive - Construct mathematics arguments that ● Create precise conjecture, using definitions,...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Construct mathematics arguments that ● Create precise conjecture, using definitions, previously established results, and stated assumptions ● Generalize logical relationships across cases ● Justify (and refute) conclusions with evidence and mathematical principles ● Evaluate and extend others’ arguments Features
<!-- standard-text:end -->
