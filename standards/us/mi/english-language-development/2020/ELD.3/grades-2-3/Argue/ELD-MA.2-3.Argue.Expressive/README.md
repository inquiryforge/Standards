# ELD-MA.2-3.Argue.Expressive - Construct mathematics arguments that ● Create conjecture using definitions ●...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Construct mathematics arguments that ● Create conjecture using definitions ● Generalize commonalities across cases ● Justify conclusion steps and strategies in simple patterns ● Identify and respond to others’ arguments Features
