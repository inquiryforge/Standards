# ELD-MA.6-8.Argue.Expressive - Construct mathematics arguments that ● Create conjecture, using definitions and...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Construct mathematics arguments that ● Create conjecture, using definitions and previously established results ● Generalize logic across cases ● Justify conclusions with evidence and mathematical facts ● Evaluate and critique others’ arguments Features
