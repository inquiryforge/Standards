# ELD-SS.2-3.Explain.Interpretive - Interpret social studies explanations by ● Determining types of sources for...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Interpret social studies explanations by ● Determining types of sources for answering compelling and supporting questions about phenomena or events ● Analyzing sources for event sequences and/or causes/effects ● Evaluating disciplinary concepts and ideas associated with a compelling or supporting question Language Functions and Sample Language
