# ELD-LA.2-3.Inform.Expressive - Construct informational texts in language rts that ● Introduce and define topic...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Construct informational texts in language rts that ● Introduce and define topic and/or entity for audience ● Add details to define, describe, compare, and classify topic and/or entity ● Develop coherence and cohesion throughout text Features
<!-- standard-text:end -->
