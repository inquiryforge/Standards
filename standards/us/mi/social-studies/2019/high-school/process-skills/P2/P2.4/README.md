# P2.4 - Use relevant information from multiple credible sources representing a wide range...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use relevant information from multiple credible sources representing a wide range of views considering the origin, authority, structure, and context to answer a compelling or supporting question.
