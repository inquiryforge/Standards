# G1.0.2 - Describe places using absolute location or relative location.

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Describe places using absolute location or relative location.

Examples may include but are not limited to: home address (absolute location), positional words such as in front of, behind, between (relative location).
<!-- standard-text:end -->
