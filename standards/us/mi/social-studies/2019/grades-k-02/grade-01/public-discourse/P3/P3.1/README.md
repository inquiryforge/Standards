# P3.1 - Identifying and Analyzing Public Issues

[Parent](../README.md)

## Source text

<!-- standard-text:start -->
Clearly state a problem as a public policy issue, analyze various perspectives, and generate and evaluate possible alternative resolutions.
<!-- standard-text:end -->
