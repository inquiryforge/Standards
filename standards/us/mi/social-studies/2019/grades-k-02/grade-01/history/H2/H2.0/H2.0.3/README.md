# H2.0.3 - Use historical sources to draw possible conclusions about family or school life in...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use historical sources to draw possible conclusions about family or school life in the past.

Examples may include but are not limited to: photos, diaries, oral histories, videos, artifacts.
<!-- standard-text:end -->
