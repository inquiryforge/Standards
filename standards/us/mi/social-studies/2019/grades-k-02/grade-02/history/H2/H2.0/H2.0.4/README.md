# H2.0.4 - Describe changes in the local community over time.

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Describe changes in the local community over time.

Examples may include but are not limited to: types of businesses, architecture and landscape, jobs, transportation, population.
