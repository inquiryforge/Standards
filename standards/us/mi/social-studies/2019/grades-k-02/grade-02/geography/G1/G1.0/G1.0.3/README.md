# G1.0.3 - Use maps to describe the location of the local community within the state of...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use maps to describe the location of the local community within the state of Michigan in relation to other significant places in the state.

Examples may include but are not limited to: next to, near, between, cardinal directions, comparison.
<!-- standard-text:end -->
