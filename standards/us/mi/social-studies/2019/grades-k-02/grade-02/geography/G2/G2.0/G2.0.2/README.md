# G2.0.2 - Describe how the local community is part of a larger region.

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Describe how the local community is part of a larger region.

Examples may include but are not limited to: county, metropolitan area, tribal reservation, state.
