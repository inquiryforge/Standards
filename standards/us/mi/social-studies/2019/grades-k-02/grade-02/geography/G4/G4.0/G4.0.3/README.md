# G4.0.3 - Use components of culture to describe diversity in the local community.

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use components of culture to describe diversity in the local community.

Examples may include but are not limited to: foods, language, religion, traditions.
<!-- standard-text:end -->
