# C3.0.2 - Use examples to describe how local government affects the lives of people in a...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use examples to describe how local government affects the lives of people in a community.

Examples may include but are not limited to: setting speed limits to promote safety, putting up traffic lights, clearing roads, monitoring water quality, removing unsafe buildings.
<!-- standard-text:end -->
