# G5.0.1 - Describe ways in which the environment provides for basic human needs and wants.

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Describe ways in which the environment provides for basic human needs and wants.

Examples may include but are not limited to: food, shelter, clothing.
