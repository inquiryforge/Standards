# C5.0.1 - Describe situations in which they demonstrated self-discipline and individual...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Describe situations in which they demonstrated self-discipline and individual responsibility.

Examples may include but are not limited to: caring for a pet, completing chores, following school rules, working in a group, taking turns.
<!-- standard-text:end -->
