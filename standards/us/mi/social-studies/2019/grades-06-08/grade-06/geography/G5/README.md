# G5 - ENVIRONMENT AND SOCIETY

[Parent](../README.md)

## Source text

<!-- standard-text:start -->
Explain that the physical environment is modified by human activities, which are influenced by the ways in which human societies value and use the Earth’s natural resources, and by Earth’s physical features and processes. Explain how human action modifies the physical environment and how physical systems affect human systems.
<!-- standard-text:end -->
