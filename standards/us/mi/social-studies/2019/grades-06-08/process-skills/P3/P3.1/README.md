# P3.1 - Clearly state an issue as a question of public policy, gather and interpret...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Clearly state an issue as a question of public policy, gather and interpret information about that issue, and generate and evaluate possible alternative resolutions.
