# G2.0.1 - Use a variety of visual materials and data sources to describe ways in which...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use a variety of visual materials and data sources to describe ways in which Michigan can be divided into regions.

Examples may include but are not limited to: physical features (lakes versus land), land use (forest, agriculture, urban), and political (state, county, and tribal boundaries).
<!-- standard-text:end -->
