# G4.0.4 - Use data and current information about the Anishinaabek and other Indigenous...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use data and current information about the Anishinaabek and other Indigenous Peoples living in Michigan today to describe the cultural aspects of modern life.

Examples may include but are not limited to: tribal citizenship, tribal governments, treaty rights, reservation boundaries, cultural events.
<!-- standard-text:end -->
