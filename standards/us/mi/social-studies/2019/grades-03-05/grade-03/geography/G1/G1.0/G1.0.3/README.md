# G1.0.3 - Use a world map to describe North America in relation to the equator and other...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use a world map to describe North America in relation to the equator and other continents and oceans, and Michigan within North America.

Examples may include but are not limited to: locate Michigan in relation to the United States, the North Pole, and the equator.
<!-- standard-text:end -->
