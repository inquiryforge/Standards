# H3.0.3 - Describe the causal relationships between three events in Michigan’s past.

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Describe the causal relationships between three events in Michigan’s past.

Examples may include but are not limited to: the Erie canal, more people came, statehood.
