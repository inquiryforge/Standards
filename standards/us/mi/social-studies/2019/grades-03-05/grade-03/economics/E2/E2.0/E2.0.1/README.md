# E2.0.1 - Using a Michigan example, explain how specialization leads to increased...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Using a Michigan example, explain how specialization leads to increased interdependence.

Examples may include but are not limited to: cherries grown in Michigan are sold in Florida; oranges grown in Florida are sold in Michigan.
