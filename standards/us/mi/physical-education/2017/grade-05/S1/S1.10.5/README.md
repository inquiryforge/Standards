# S1.10.5 - Performs curling, twisting, and stretching actions with correct application in...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Performs curling, twisting, and stretching actions with correct application in dance, gymnastics and small-sided practice tasks in game environments.
