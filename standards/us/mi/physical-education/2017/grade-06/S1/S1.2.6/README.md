# S1.2.6 - Throws with a mature pattern for distance or power appropriate to the practice task...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Throws with a mature pattern for distance or power appropriate to the practice task (e.g., distance = outfield to home plate; power = 2nd base to 1st base).
<!-- standard-text:end -->
