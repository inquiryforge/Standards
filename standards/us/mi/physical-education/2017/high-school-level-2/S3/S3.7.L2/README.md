# S3.7.L2 - Designs and implements a strength and conditioning program that develops balance in...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Designs and implements a strength and conditioning program that develops balance in opposing muscle groups (agonist-antagonist) and supports a healthy, active lifestyle.
