# S1.22.3 - Volleys an object with an underhand or sidearm striking pattern, sending it forward...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Volleys an object with an underhand or sidearm striking pattern, sending it forward over a net, to the wall or over a line to a partner, while demonstrating 4 of the 5 elements of a mature pattern.
<!-- standard-text:end -->
