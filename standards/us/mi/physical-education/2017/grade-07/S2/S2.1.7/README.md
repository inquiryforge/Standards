# S2.1.7 - Reduces open space by using locomotor movements (e.g. walking, running, jumping, and...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Reduces open space by using locomotor movements (e.g. walking, running, jumping, and landing, changing size and shape of the body) in combination with movement concepts (e.g. reducing the angle in space, reducing distance between player and goal).
