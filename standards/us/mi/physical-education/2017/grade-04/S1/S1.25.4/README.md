# S1.25.4 - Strikes an object with a long-handled implement (e.g. hockey stick, golf club, bat,...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Strikes an object with a long-handled implement (e.g. hockey stick, golf club, bat, tennis or badminton racket) while demonstrating 3 of the 5 critical elements of a mature pattern for the implement (grip, stance, body orientation, swing plane, and follow-through).
