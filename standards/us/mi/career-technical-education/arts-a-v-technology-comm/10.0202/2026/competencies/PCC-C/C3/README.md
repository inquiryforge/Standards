# C3 - Demonstrate skills and techniques essential for editing and enhancing content,...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Demonstrate skills and techniques essential for editing and enhancing content, demonstrating methods to create a coherent project that effectively communicates its intended message or story for distribution.
