# A2.S008 - Create and manipulate raster images using photo-editing software and tools, e.g.,...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Create and manipulate raster images using photo-editing software and tools, e.g., crop, perspective pencil, clone stamp, history brush, eraser, background eraser, magic eraser, gradient, and paint bucket.
