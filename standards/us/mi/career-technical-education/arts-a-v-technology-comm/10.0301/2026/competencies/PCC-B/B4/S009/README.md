# B4.S009 - Explain resolution requirements for wide format printing, such as dots per inch...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Explain resolution requirements for wide format printing, such as dots per inch (DPI), image interpolation, and raster image processing (RIP) software used to optimize image quality for large-format prints.
