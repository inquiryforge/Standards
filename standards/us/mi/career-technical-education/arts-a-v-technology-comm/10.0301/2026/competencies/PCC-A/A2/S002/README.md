# A2.S002 - Demonstrate page layout skills including adding a title, a header, body text, block...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Demonstrate page layout skills including adding a title, a header, body text, block quote, a footer, a caption, generating a table of contents, an index, page size, page orientation, facing pages, spread, bleed, trim, slug, master page, alternate page layout, columns, gutters, margins, breaks, glyphs, and frames.
