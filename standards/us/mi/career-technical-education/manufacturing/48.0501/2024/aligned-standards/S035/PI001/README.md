# S035.PI001 - Post code. Begin with CAD model. Select CNC process. Select cutting tool and...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Post code. Begin with CAD model. Select CNC process. Select cutting tool and machining parameters. Create toolpath. Verify toolpath. Post process. Transfer G & M -code program to CNC machine. Establish job parameters including CNC coordinate system and stock shape/size.
