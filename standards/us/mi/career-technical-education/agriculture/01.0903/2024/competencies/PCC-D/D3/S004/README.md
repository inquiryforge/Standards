# D3.S004 - Produce and/or manage animals in domesticated and/or natural environments using an...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Produce and/or manage animals in domesticated and/or natural environments using an application of knowledge regarding anatomy and physiology to enhance animal production.
