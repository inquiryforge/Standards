# X.AP.2.d - FOD Cans and Containers—Foreign Object Debris cans and containers are strategically...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
FOD Cans and Containers—Foreign Object Debris cans and containers are strategically placed in FOD designated areas. FOD cans and containers are very useful tools in preventing foreign objects from migrating into aerospace products. It is everyone’s responsibility to utilize FOD cans and containers for any trash or foreign material in a FOD designated area.
