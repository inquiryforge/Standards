# X.AP.3.g - Tool Identification—Tools are marked for issue, return and accountability. Every...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Tool Identification—Tools are marked for issue, return and accountability. Every tool that is assigned to a specific area or tool box is marked with one or more of the following methods: tags, sensors, bar codes, laser etching/engraving, and color code
