# X.AP.3.k - Electronic Tool Accountability System—Tools can be tracked to a user by a unique...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Electronic Tool Accountability System—Tools can be tracked to a user by a unique identifier such as a badge. The electronic tool accountability system utilizes electronic sensors and/or bar codes that identify each individual tool (see “Tool Identification” in this section).
