# X.AP.3.b - Shadow Box / Board— A toolbox or storage board with specifically, marked locations...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Shadow Box / Board— A toolbox or storage board with specifically, marked locations (e.g. foam cutouts) for each tool in the tool box or storage board so that a missing tool is readily noticeable. A tool box or storage board can be inventoried in 60 seconds or less. Shadow boxing with foam cutouts is very popular and is often used in conjunction with other methods.
