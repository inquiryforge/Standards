# X.AP.3.e - Tool Inventory Sheets / Logs—Written Tool Inventory Sheets / Logs are a listing of...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Tool Inventory Sheets / Logs—Written Tool Inventory Sheets / Logs are a listing of tools and materials that must be checked in and out when entering or departing a FOD designated area. Completed Tool Inventory Sheets / Logs are required prior to the FOD designated area closeout.
<!-- standard-text:end -->
