# X.AP.8.l - Electro-Static sensitive devices should be properly protected to avoid damage....

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Electro-Static sensitive devices should be properly protected to avoid damage. Materials that are used to protect electro-explosive devices and sensitive electronic components should be kept clean, covered, and stored away from ordinary non-static safe materials.
<!-- standard-text:end -->
