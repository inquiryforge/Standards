# X.AP.3.i - Tool Condition—Assuring that a tool’s condition is clean, undamaged and free of...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Tool Condition—Assuring that a tool’s condition is clean, undamaged and free of Foreign Objects prior to use is a professional FOD prevention method. It is very important to visually inspect tools for all the conditions described herein. Tool condition inspections should be accomplished prior to and immediately after job completion. Broken or worn Tools - Visually inspect tools for broken or worn areas that can become FOD. Damaged - Any damaged tools should be repaired or replaced to prevent the damaged tool from becoming FOD. Dirty - Ensure the tools are clean and ready for use prior to each use. Flaking - (Chrome flaking) Flaking is a hidden foreign ofject and can become a serious problem if undetected.
<!-- standard-text:end -->
