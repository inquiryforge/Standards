# X.AP.8.d - Parts and assemblies should be packaged in a manner that will preclude any chance of...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Parts and assemblies should be packaged in a manner that will preclude any chance of one item making contact with another during normal handling operations.
