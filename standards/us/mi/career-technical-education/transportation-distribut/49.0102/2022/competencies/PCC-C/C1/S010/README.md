# C1.S010 - Select an entry altitude that will allow the Task to be completed no lower than...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Select an entry altitude that will allow the Task to be completed no lower than 1,500 feet AGL (ASEL, ASES) or 3,000 feet AGL (AMEL, AMES).
<!-- standard-text:end -->
