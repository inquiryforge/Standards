# PI013 - HT- 5.2: Identify resources to utilize in various emergency situations for self,...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
HT- 5.2: Identify resources to utilize in various emergency situations for self, co-workers and guests/customers. Detail steps to use in medical emergencies. List resources for assistance with environmental issues. Name the resources for assistance in crimes or accidents. Detail how to access help in a terrorist situation.
