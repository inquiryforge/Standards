# B2.S001 - Execute the procedures involved with administering basic first aid and CPR in order...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Execute the procedures involved with administering basic first aid and CPR in order to respond to workplace emergencies that arise in the law, public safety, security and corrections workplace.
