# 8.EE.A.1 - Know and apply the properties of integer exponents to generate equivalent numerical...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Know and apply the properties of integer exponents to generate equivalent numerical expressions. For example, 3^(2) × 3^(–5) = 3^(–3) = 1/3^(3) = 1/27.
<!-- standard-text:end -->
