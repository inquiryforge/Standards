# 2.MD.D.10 - Draw a picture graph and a bar graph (with single-unit scale) to represent a data...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Draw a picture graph and a bar graph (with single-unit scale) to represent a data set with up to four categories. Solve simple put-together, take-apart, and compare problems^(4) using information presented in a bar graph.
