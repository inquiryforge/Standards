# 2.NBT.A.1b - The numbers 100, 200, 300, 400, 500, 600, 700, 800, 900 refer to one, two, three,...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
The numbers 100, 200, 300, 400, 500, 600, 700, 800, 900 refer to one, two, three, four, five, six, seven, eight, or nine hundreds (and 0 tens and 0 ones).
<!-- standard-text:end -->
