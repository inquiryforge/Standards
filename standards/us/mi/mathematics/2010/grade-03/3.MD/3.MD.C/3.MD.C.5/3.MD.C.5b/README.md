# 3.MD.C.5b - A plane figure which can be covered without gaps or overlaps by n unit squares is...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
A plane figure which can be covered without gaps or overlaps by n unit squares is said to have an area of n square units.
<!-- standard-text:end -->
