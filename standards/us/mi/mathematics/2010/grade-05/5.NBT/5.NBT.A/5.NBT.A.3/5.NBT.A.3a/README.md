# 5.NBT.A.3a - Read and write decimals to thousandths using base-ten numerals, number names, and...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Read and write decimals to thousandths using base-ten numerals, number names, and expanded form, e.g., 347.392 = 3 × 100 + 4 × 10 + 7 × 1 + 3 × (1/10) + 9 × (1/100) + 2 × (1/1000).
<!-- standard-text:end -->
