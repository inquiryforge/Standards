# 5.MD.C.3b - A solid figure which can be packed without gaps or overlaps using n unit cubes is...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
A solid figure which can be packed without gaps or overlaps using n unit cubes is said to have a volume of n cubic units.
<!-- standard-text:end -->
