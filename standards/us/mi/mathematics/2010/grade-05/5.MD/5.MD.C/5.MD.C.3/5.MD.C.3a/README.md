# 5.MD.C.3a - A cube with side length 1 unit, called a “unit cube,” is said to have “one cubic...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
A cube with side length 1 unit, called a “unit cube,” is said to have “one cubic unit” of volume, and can be used to measure volume.
