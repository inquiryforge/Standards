# N-CN.C.8 - (+) Extend polynomial identities to the complex numbers. For example, rewrite x^(2)...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
(+) Extend polynomial identities to the complex numbers. For example, rewrite x^(2) + 4 as (x + 2i)(x – 2i).
