# A-SSE.A.2 - Use the structure of an expression to identify ways to rewrite it. For example, see...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use the structure of an expression to identify ways to rewrite it. For example, see x^(4) – y^(4) as (x^(2))^(2) – (y^(2))^(2), thus recognizing it as a difffference of squares that can be factored as (x^(2) – y^(2))(x^(2) + y^(2)).
<!-- standard-text:end -->
