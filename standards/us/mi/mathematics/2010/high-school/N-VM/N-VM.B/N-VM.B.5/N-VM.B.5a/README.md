# N-VM.B.5a - Represent scalar multiplication graphically by scaling vectors and possibly...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Represent scalar multiplication graphically by scaling vectors and possibly reversing their direction; perform scalar multiplication component-wise, e.g., as c(v , v ) = (cv , cv ).
