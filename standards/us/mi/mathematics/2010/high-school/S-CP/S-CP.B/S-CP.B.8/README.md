# S-CP.B.8 - (+) Apply the general Multiplication Rule in a uniform probability model, P(A and B)...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
(+) Apply the general Multiplication Rule in a uniform probability model, P(A and B) = P(A)P(B|A) = P(B)P(A|B), and interpret the answer in terms of the model.
<!-- standard-text:end -->
