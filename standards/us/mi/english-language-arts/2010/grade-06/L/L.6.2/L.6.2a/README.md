# L.6.2a - Use punctuation (commas, parentheses, dashes) to set off...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use punctuation (commas, parentheses, dashes) to set off nonrestrictive/parenthetical elements.*

> Source * marker: skills particularly likely to require continued attention in higher grades; see source Language Progressive Skills table.
