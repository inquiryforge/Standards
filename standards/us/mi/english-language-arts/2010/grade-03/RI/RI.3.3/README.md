# RI.3.3 - Describe the relationship between a series of historical events, scientific ideas or...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Describe the relationship between a series of historical events, scientific ideas or concepts, or steps in technical procedures in a text, using language that pertains to time, sequence, and cause/effect. Craft and Structure
<!-- standard-text:end -->
