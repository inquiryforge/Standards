# L.3.4c - Use a known root word as a clue to the meaning of an unknown word with the same root...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Use a known root word as a clue to the meaning of an unknown word with the same root (e.g., company, companion).
