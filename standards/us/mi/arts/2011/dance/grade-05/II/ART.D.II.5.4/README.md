# ART.D.II.5.4 - Create a dance phrase, accurately repeat it, and then vary it by making changes in...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Create a dance phrase, accurately repeat it, and then vary it by making changes in the elements of dance: time, space, force, and energy.
