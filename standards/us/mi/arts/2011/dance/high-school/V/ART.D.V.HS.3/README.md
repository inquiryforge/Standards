# ART.D.V.HS.3 - Create an inter-disciplinary project based on a theme identified by the student,...

[Parent](../README.md)

## Standard

<!-- standard-text:start -->
Create an inter-disciplinary project based on a theme identified by the student, including dance and two other disciplines, such as history, science, multi-media, etc.
